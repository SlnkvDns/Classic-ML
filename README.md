# Classic Machine Learning Portfolio

Учебные и практические проекты по классическому машинному обучению. Репозиторий организован по темам; ноутбуки с исходными заданиями сохранены, а имена нормализованы для удобной навигации.

## Содержание

| Раздел | Темы |
| --- | --- |
| `notebooks/01-eda` | Исследовательский анализ, очистка и кодирование данных |
| `notebooks/02-regression` | Линейные модели, регуляризация, полиномиальные признаки и настройка параметров |
| `notebooks/03-classification` | KNN, логистическая регрессия, наивный Байес и метрики классификации |
| `notebooks/04-trees-ensembles` | Деревья решений и ансамбли |
| `notebooks/05-clustering` | K-means, иерархическая кластеризация и оценка кластеров |
| `notebooks/06-dimensionality-reduction` | Отбор признаков и PCA |
| `notebooks/07-neural-networks` | MLP и полносвязные сети на scikit-learn и TensorFlow/Keras |
| `projects/portal-condition` | Сквозная задача регрессии: подготовка данных, выбросы, признаки и сравнение моделей |
| `projects/yandex-ml` | Практическое задание по линейным моделям |
| `notebooks/08-statistics` | Описательная статистика |
| `archive/` | Черновики, копии, вспомогательные и неразобранные материалы |

## Навыки и инструменты

Python, Jupyter, pandas, NumPy, matplotlib, seaborn, scikit-learn, TensorFlow/Keras; исследовательский анализ данных, предобработка, регрессия, классификация, кластеризация, снижение размерности, подбор гиперпараметров и оценка моделей.

## Данные и запуск

В ноутбуках используются как встроенные наборы данных scikit-learn, так и внешние CSV/PKL-файлы. Некоторые исходные задания ссылаются на файлы из локальной папки `data/` или на абсолютные пути с компьютера автора. Эти данные не входят в репозиторий, поэтому для повторного запуска соответствующего ноутбука потребуется предоставить исходный набор и обновить путь. Ноутбуки сгруппированы для навигации; их код и результаты вычислений не переписывались.

Базовые зависимости указаны в [`requirements.txt`](requirements.txt). Отдельные ноутбуки могут требовать дополнительные библиотеки (например, Optuna, CatBoost, PyCaret или Keras Tuner).
